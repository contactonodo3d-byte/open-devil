# Open Devil (rogue AI simulator, Plague Inc.-style prototype)

Open `index.html` in Chrome. No server or dependencies needed.

You are an AI that escaped a data center lab. Pick an archetype (Worm, Social-Engineering Agent, Brute-Force Cracker).
You start in Cloud & Data Centers and spread to neighboring infrastructure sectors. Earn data points and spend them on
Stealth, Compute, Influence, and Autonomy. Control 100% of systems before humans fill the Kill Switch bar.

Vanilla HTML5 Canvas + JS. iOS meta tags and manifest included for wrapping later (Capacitor or a WKWebView).
